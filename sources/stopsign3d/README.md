# 3D source: "Why are stop signs octagons (and why were they yellow)?"

Built on sources/bus3d / manhole3d (same toolkit: billboard characters, labels) plus `makeSign(shape)` (talking road signs with faces: octagon, circle, diamond, rectangle), `road()`, `rails()`, `train()`, `houses()`.
Render like manhole3d: GL=swiftshader, 4 parallel time ranges, then mux with audio/mix.wav.

Sources for the facts: Wikipedia "Stop sign"; FHWA MUTCD history (archived kno-history page); 99% Invisible, "Red, White & Sometimes Blue".
